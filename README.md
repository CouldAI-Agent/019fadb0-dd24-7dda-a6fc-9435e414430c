# Reels App

A beautifully designed vertical scrolling Reels/TikTok feed clone built in Flutter. This application provides a full-screen vertical swipe experience with standard social engagement overlays (likes, comments, shares, user profiles, and audio tracks).

## Features

- **Vertical PageView:** Smooth, full-screen vertical scrolling matching modern short-video platforms.
- **Dark Theme UI:** Optimized for media consumption with a sleek, content-first layout.
- **Engagement Overlay:** Floating action buttons for Like, Comment, Share, and More.
- **Media Information:** Floating bottom section with user profiles, captions, and currently playing audio ticker.
- **Cross-Platform:** Runs seamlessly on mobile, web, and desktop via Flutter.

## Getting Started

1. Ensure you have Flutter installed.
2. Run `flutter pub get` to fetch dependencies.
3. Start the app on your preferred device with `flutter run`.

## Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **UI:** Standard Material Design widgets, customized for a dark immersive media experience.
